# QuizMario — Vocab Spotlight

Offline / GitHub Pages HTML5 vocab trainer with Anki-lite SRS and custom streak VO.

## Features

- 8 sets × 50 words, Anki-lite SRS (Good / Easy / Again)
- Clearance unlocks next set
- Custom killstreak VO in `audio/`
- **Progress backup:** export/import JSON + pasteable backup code (progress is per-browser unless exported)
- **Add to Home Screen:** `manifest.webmanifest` + apple-touch-icon (iPhone Safari → Share → 添加到主屏幕)

## Local

Open `index.html` or run `Play QuizMario.command`.

## Deploy note

Static site — relative paths. Do **not** commit `audio/source_gumeilu3.wav` (large source).
