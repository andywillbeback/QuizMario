# 单词朗读记录

## 当前可用范围

`grok/` 的单词卡新增“单词朗读”。中考、高考、雅思使用同一个入口。学生主动点按后才加载录音模块并请求麦克风；每次最多 8 秒，完成后可回听当前录音。进入新卡片、离开练习页、切换账号或页面进入后台时，停止录音并释放临时音频。

拼写及中文选英文题在答案揭晓前隐藏入口，避免显示或播放答案。搭配题显示期间不把短语录音记到宿主单词。示范播放会中断正在进行的录音，开始录音也会停止示范和连杀语音。

当前版本没有接入自动发音评测、转写或人工评分。每个词只显示“未练习”或“已录音 · 待验证”，并显示有效录音次数、最近练习时间。录音成功、检测到声音、示范已经播放，都不能推导发音准确、通过或单词掌握。

音频 Blob 仅留在当前页面内存供本次回听，不上传、不放入 localStorage、不作为可跨设备回听的历史档案。刷新或离开当前卡片后，声音不能再次回听；练习元数据仍随账号保存和同步。录音入口不强制阻塞现有答题流程，麦克风不可用时仍能继续学习。

## 数据与账号归属

每张卡片的 `oralOutput.attempts` 以随机稳定 ID 保存不可变记录：

```js
{
  version: 1,
  attempts: {
    oral_example: {
      id: "oral_example",
      at: "2026-11-20T08:00:00.000Z",
      durationMs: 1800,
      mimeType: "audio/webm;codecs=opus",
      status: "recorded",
      assisted: true,
      referencePlayed: false,
      audioCheck: "signal_detected"
    }
  }
}
```

- `assisted: true` 表示看着单词朗读，不是独立回忆测验。
- `referencePlayed` 只记录本卡片示范语音的实际开始播放事件，不声称学生听到或听懂。
- `audioCheck` 为 `signal_detected` 或 `unchecked`。前者仅是音量信号检测，不能证明录到了人声、英语或正确单词；后者表示浏览器无法可靠进行此项检查。
- 少于 350 毫秒、空文件，以及音量监测可用时的持续静音，不保存为有效练习记录。
- 未配置评测服务，数据没有 `score`、准确率、通过或需再练判断。

每次录音捕获当前账号、卡片 key 和界面代次。请求权限、结束录音等异步回调必须重新核对归属；取消后晚到的麦克风流立即释放。新元数据先成功写入账号缓存，再更新内存并交给现有同步队列。

仅有朗读记录的存档也必须上传，不能被视作空进度。合并时按记录 ID 取并集，不截断历史；同 ID 保留完整原记录。录音不会增加 `studiedCount`、SRS、拼写成绩、词义正确次数或通关状态。未来评测应另存独立结果并关联原录音 ID，不能改写原始 `status: "recorded"` 证据。

## 费用与后续真实评测

当前浏览器录音和回听不调用 AI API，不新增语音服务调用费用，也不新增音频云存储。现有网站和账号同步仍使用原来的托管服务与配额。

自动评测候选是讯飞英语语音评测，而不是将普通语音识别文本一致视作发音准确。官方接口文档列出默认每日 500 次调用；实际账号可用权益、期限、并发、商用条件及超额计费应在服务开通时确认：

https://www.xfyun.cn/doc/Ise/IseAPI.html

本仓库当前没有讯飞账号凭据、服务端评测桥接或自动计费配置。本次改动没有购买、开通付费服务，也没有使用任何学生音频做外部评测。

启用真实评测还需要配置受保护的服务端：验证学生会话、校验目标词和音频大小/时长、转成评测接口支持的格式、在服务端保管密钥并签名、限制每日额度、保存独立评测结果。免费额度不足或服务异常时应保留“待验证”，不能默认为通过，也不能未经授权自动切换付费。浏览器录音 Blob 格式不能直接假定符合评测引擎的 PCM 要求。

## 验证

新增测试文件：

- `tests/oral-output.test.js`：录音生命周期、权限拒绝和超时、空/短/静音音频、8 秒上限、取消及麦克风释放。
- `tests/oral-output-sync.test.js`：账号隔离、原记录保留、跨设备追加、断网重试、丢失 ACK 后不重复、熟练度不受影响。
- `tests/oral-output-browser.test.js`：真实 Chromium 页面、375px 布局、按需加载、入口隐藏、录音/回听、重载保持记录、换词/退出/换账号的异步归属。

浏览器测试使用虚构账号和模拟麦克风，不代表已在真实 iPhone、Android 或微信内置浏览器测试，也不验证声学评分准确度。发布仍须通过仓库既有的 `node tools/verify-learning-contracts.js` 完整检查。
